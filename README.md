Home Credit LAP Qualification Voice Agent

Project Overview
An AI voice agent built using Retell AI to conduct preliminary qualification for a Home Credit Loan Against Property (LAP) offer of up to ₹75 lakh.

Objective
The agent explains the offer, checks customer eligibility, handles disqualification scenarios, routes existing-loan transfer requests, and directs eligible customers to a senior loan expert.

Technology Used
- Retell AI
- AI voice agent
- Prompt engineering

Eligibility Checklist
1. Property type
2. Ownership status
3. Availability of original property documents
4. Requested loan amount
5. Occupation and income mode
6. Estimated property market value
7. Repayment tenure

Special Conversation Flows
- Customer verification and callback requests
- Agricultural property disqualification
- Missing original documents
- Cash-income disqualification
- Loan amounts above ₹75 lakh
- Existing-loan and EMI-reduction requests
- Eligible-customer handoff to a senior loan expert

Testing
Initial test scenarios covered:
- Eligible customer
- Agricultural property disqualification
- Existing-loan / EMI-transfer request

Additional edge cases require separate validation.

Project Files
- `Home_Credit_LAP_System_Prompt.txt` — system instructions for the voice agent
- Call recordings and logs — provided separately through the assignment submission links

Disclaimer
This is a preliminary qualification demonstration. It does not approve loans or guarantee loan disbursement.
